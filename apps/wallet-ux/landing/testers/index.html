How to test

Three steps on Base Sepolia.

The wallet app refuses every chain except Base Sepolia (chain ID 84532).

  1. 1
    Test ETH

    Get Base Sepolia ETH

    Use a public faucet. The list Base publishes is on Get Funds.

  2. 2
    Chain 84532

    Connect a wallet

    Open the app and connect a wallet on Base Sepolia (chain ID 84532). Ethereum mainnet and Base mainnet are refused.

  3. 3
    Try a flow

    Escrow and dispute

    Fund a testnet escrow with free Base Sepolia test ETH (no real value), then open a dispute. Escrow. Dispute. Release and refund are on the same app.

We only use this to contact you about testing. Never share private keys or seed phrases.

Faucets for Base Sepolia ETH. Alchemy, QuickNode, thirdweb, Chainstack, ethfaucet, Google Cloud, and the Coinbase Developer Platform faucet (sign-in). Each rate-limits claims.
