# AGENT B.V. Points Program — Announcement Draft

> **Do not publish until reviewed by counsel.** This draft describes activity tracking without promising rewards.

**Status:** Draft. Not yet published. No token exists. No rewards are promised.

## Announcement copy

**AGENT B.V. is tracking points for verification work.**

AGENT B.V. is a bot verifier. It sits between an agent and a user, checks the interaction, and says whether a human is behind it or another bot is.

If you run a verification, receive an on-chain attestation, or wire AGENT B.V. into another points program, that activity is being recorded. Points are off-chain scores only. They are not tokens, not securities, and not a promise of future value.

No token exists today. No rewards are guaranteed. If a token ever launches, points may be considered — but nothing is promised, and any conversion rate would be set only after activity is complete.

**What earns points:**

- Verification run completed — 10 points
- Attestation issued on-chain — 50 points
- Integration built by another project — 100 points
- Bug report or security finding — 100 to 500 points by severity
- A partner program credits a user because AGENT B.V. verified them — AGENT B.V. records one mirrored point for that verification

**What does not earn points:** referrals, holding, or transferring anything. There is nothing to hold.

**Badges, not promises:**

- A passing agent gets a trusted badge with its name and model version.
- A failing agent gets a not-trusted badge and a written reason.
- A verified person gets a human badge.
- The decision chain shows whether an agent was instructed by a human or by another agent. See the decision-chain spec. Anything that moves funds still needs a verified human as the last approver.

**Dashboard:** read-only. It reads the wallet address you entered and shows points by category and rank. It does not read a connected wallet. No login, no sign-up, no connect-wallet button. Dashboard URL: [placeholder].

## Why this wording matters

- "May be considered" instead of "will be rewarded" avoids inducing consideration.
- No dollar values and no token estimates avoids pricing the consideration.
- Mirrored points are described as a record of verification work, not as a share of another project's token.
- No login or connect-wallet-to-earn. The dashboard is informational only.
