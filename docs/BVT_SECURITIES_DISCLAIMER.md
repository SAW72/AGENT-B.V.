## What staking is (and is not)

If staking is enabled, it is an **operational performance bond**: auditors (and similar operators) lock tokens so they can be **slashed** for documented misconduct (for example, fake hashes or rigged scores). That is a **security deposit for work**, not a marketed investment contract.

Unstake cooldowns, governance lockups, and fee splits exist to run the experiment — not to promise profit.
